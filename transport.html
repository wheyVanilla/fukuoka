Day 2｜11/1（日）八女

最省腦方案：全程 Suica。西鉄福岡（天神）→西鉄久留米→西鐵巴士 30/31/32 →「福島」下車。
Step 1｜飯店走到西鉄福岡（天神）駅
步行約 6–8 分鐘。進站後找 天神大牟田線・大牟田方面。
Maps
Step 2｜西鉄福岡（天神） → 西鉄久留米
優先搭 特急。西鐵的特急不需要另買特急券；直接 Suica 進出。
現行運價：¥720／人／單程。
Step 3｜西鉄久留米 → 福島（八女）
出電車後去西鉄久留米巴士中心。找往 八女営業所方向的 30／31／32；其中 31 是主幹路線。
你們要在 「福島」下車，不是「福島高校前」，也不必坐到八女営業所。
Suica 可用。現行公開資料顯示西鉄久留米→八女営業所全程 ¥600；「福島」在終點前，所以實際會低於或等於 ¥600。因 2026/10 有西鐵巴士改點，精確福島票價等新版完全生效後再鎖，不放假精準數字。
現場判斷：看電子看板／司機前方顯示有「福島・八女営業所」即可。30、31、32 都可以，不必死等某一號。
西鐵官方時刻／運賃Maps 即時轉乘
Step 4｜福島 → 白壁老街
下車後照 Maps 步行進八女福島町並區；景點之間以步行為主。
八女福島 Maps
Step 5｜回程：福島 → 西鉄久留米 → 西鉄福岡（天神）
回到去程下車點對向的 福島站牌，搭 30／31／32 往西鉄久留米／JR久留米方向；在 西鉄久留米下車，再搭特急回天神。
不要：為了省幾十日圓去研究 FUKUOKA 1DAY PASS。西鐵往返 ¥1,440，加上八女巴士往返仍低於 ¥2,980 Pass 的門檻。

Day 4｜11/3（二・文化日）下關＋門司港

今天唯一要先買的 Pass：JR KYUSHU MOBILE PASS「FUKUOKA WIDE」2日 ¥3,500／人。適用普通／快速＋特急自由席，包含門司港；不含博多～小倉山陽新幹線。
Step 1｜飯店 → 博多駅
最長移動日，不先走 1.9 km。優先 Taxi；若不用 Taxi 再搭市區交通。
Taxi：博多駅（JR Hakata Station）
Maps
Step 2｜博多 → 小倉｜Sonic
主方案：08:02 特急 Sonic 5 自由席 → 08:56 小倉。進站／出示方式依 Mobile Pass 指示；搭自由席，不另買特急券。
不要搭山陽新幹線。Hakata–Kokura Shinkansen 不在這張 Mobile Pass 範圍內。
Step 3｜小倉 → 下関｜不要在門司下車
09:14 小倉 → 09:27 下関。直接坐到底。Mobile Pass 的有效範圍到門司，但你不需要為了補票在門司下車。
到下関怎麼做：走人工閘口 → 出示 Mobile Pass → 說要補「門司から下関まで」→ 補付 ¥270／人。
このパスで博多から来ました。門司から下関までの運賃を精算したいです。
Step 4｜下関駅 → 唐戸
到 下関駅前バスターミナル。找 1～4 號乘車處。搭最先發車、電子看板有 「唐戸」 的車即可；不用背特定 bus number。約 10 分，在 唐戸下車。
¥260／人；Suica 可用。
Step 5｜唐戸市場 → 馬關條約歷史線
全程步行：唐戸市場 → 日清講和記念館 → 春帆樓 → 赤間神宮 → 唐戸桟橋。
市場→記念館 Maps
Step 6｜唐戸桟橋 → 門司港
關門汽船。主抓 12:00；Backup 12:20。船程約 5 分。
¥400／人。
Step 7｜門司港 → 小倉 → 博多｜回程完整操作
主方案：16:42 門司港 → 約 16:56 小倉；到小倉後直接跟 「特急／Sonic／博多方面」指標走，接 17:05 Sonic 42 自由席 → 約17:55 博多。
回程全部包含在 Mobile Pass。門司港→小倉→博多不用補票、不刷 Suica、不另買特急券。
Backup A（最穩）：16:59 門司港 → 17:12 小倉；17:40 Sonic 44 → 博多。轉乘約 28 分鐘。
Backup B：若懶得轉特急，搭往博多方向的快速／區間快速，較慢但 Pass 仍涵蓋。
9 分鐘轉乘規則：主方案能接，但文化日人多。到小倉不要逛便利店、不要出站；直接轉月台。
今日核心成本：¥3,500 Pass＋¥270 跨區 JR＋¥260 巴士＋¥400 船＝約 ¥4,430／人；三人約 ¥13,290。2026/7/1 起博多～門司港 2枚きっぷ已漲到 ¥4,200，所以不選它。
路線已設計；Taxi 價當日看 GO

Day 5｜11/4（三）筑紫耶馬渓小健行＋那珂川清滝

先講清楚：中ノ島公園每週三休園，所以不去。但筑紫耶馬渓／南畑公園是不同地點。那珂川市官方把南畑公園列在筑紫耶馬渓內，秋季可看紅葉；這裡適合做 35–40 分鐘「輕健行／溪谷散步」，不是正式登山。
Step 1｜飯店 → 西鉄福岡（天神） → 大橋
飯店步行 6–8 分鐘到西鉄福岡（天神）→ 搭天神大牟田線到 大橋駅。
¥240／人；Suica。
Step 2｜大橋駅東口 → 清滝｜先用免費接駁把長距離吃掉
到 大橋駅 東口バスロータリー搭清滝免費巡回巴士。推薦 09:30 → 09:57 抵達清滝。
這樣比從大橋直接 Taxi 去山區省很多。到清滝門口後再叫 Taxi 做短距離「清滝 ↔ 南畑公園」。
清滝官方交通
Step 3｜清滝 → 南畑公園｜Taxi
抵達清滝後，在入口處叫 Taxi。建議直接跟司機約好約 45–50 分鐘後回原下車處接你們，因為山區沒有 Taxi 排班站，這比走完再臨時叫車可靠。
Taxi 目的地：南畑公園｜福岡県那珂川市大字五ケ山字ウツヲ915-39
Maps
Taxi 金額：沒有官方固定價，不填假數字。用 GO／現場車隊的即時報價；三人一起坐，按一車計。
Step 4｜南畑公園 35–40 分鐘輕健行
操作方式：同一個點下車、同一個點回來。進公園後沿可見的公園／溪谷步道散步，走 17–20 分鐘就折返，總步行約 35–40 分鐘。以紅葉、溪谷、拍照為主。
不要：沿國道 385 號為了「多走一點」往南畑水壩硬走。官方沒有提供一條給一般遊客的固定短登山 trail map；你們這天後面還要泡湯，所以只做 out-and-back。
雨天：直接取消 hiking，留在清滝。這不是必去景點。
Step 5｜南畑公園 → 清滝｜Taxi 回原點
目的地：〒811-1236 福岡県那珂川市南面里326 源泉野天風呂 那珂川清滝
Maps
Step 6｜11:30 午餐 → 家族湯 50 分鐘 → 休息
食事処棗 11:30 起。家族風呂官方為 50 分鐘；爸媽一起家族風呂，你去女大浴場。翌月預約每月 20 日開始，所以 10/20 起處理 11 月預約。
Step 7｜清滝 → 大橋 → 天神
主抓 15:20 清滝 → 15:45 大橋免費接駁；想多休息可用 15:50→16:15 或 16:20→16:45。大橋再搭西鐵回天神。
大橋→天神 ¥240／人；Suica。
今天的價格邏輯：公共交通只花西鐵往返 ¥480／人；真正的額外成本是「清滝↔南畑公園」兩段 Taxi。這比大橋一路 Taxi 到山區更符合效率／價格平衡。
已鎖定
